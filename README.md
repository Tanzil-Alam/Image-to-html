# Image-To-Html

This is a image to html converter. It converts your website design/image to a real website code in Html and css, It uses gemini to do the work. 
You have to add the api keys in the env, I have did it in live demo, but its not available in the code, because api key should be hidden. 
You will get the Gemini key from Google AI studio. And I have also added a Unsplash API key for fetching new background images, its optional 
I just did this for looks. The frontend is so simple, I used simple code here. The project is open source, anyone can update it. 



Live Demo : https://image-to-html-one.vercel.app/
